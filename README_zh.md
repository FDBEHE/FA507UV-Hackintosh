# ASUS 天选 5 FA507UV 黑苹果项目

> **这是 ASUS TUF Gaming A15 FA507UV（天选 5）的一份个人实机 Hackintosh 记录。** 本项目以作者当前实际使用的机器、EFI 配置和排错过程为基础，不是通用 EFI，也不保证适用于所有 FA507UV 机器或其他型号。不同批次的硬件、BIOS、设备 ID 和 USB 接口布局可能存在差异，请勿不经检查直接套用。

本仓库主要记录 AMD Ryzen 7 8845H 平台在 macOS 下的启动适配、设备驱动、USB/XHCI、Realtek 无线网络、蓝牙、图形、CPU 电源管理，以及 Realtek ALC256 内置扬声器修复过程。

### 已知问题与未验证项目

- **触控板：** 已有指针和手势功能，但操作体验不佳。当前配置包含 `-vi2c-force-polling`，它是后续排查时可以关注的配置项，但尚不能确定它就是手感不佳的原因。
- **蓝牙：** 键盘可连接使用，但 iPhone 12 无法正常连接；不能简单标记为蓝牙完全正常。
- **麦克风：** 输入电平条会变化，但没有完成实际录音、语音通话验证。
- **睡眠：** 合盖后风扇仍运行，睡眠行为异常。作者目前不依赖睡眠功能。
- **电源按钮：** 尚未测试，暂不作功能结论。

## EFI 目录说明

当前文档包包含 EFI 整理说明，但**尚未附上实际的 `EFI/BOOT` 和 `EFI/OC` 启动文件**。后续如补充 EFI，应使用本机当前正在使用的配置制作公开副本，而不是另行制作一套通用配置。

公开 EFI 与个人日常使用 EFI 应分开保存：

1. 个人原始 EFI 保留完整 SMBIOS 身份信息，单独备份，不公开。
2. 公开副本保留本机实际使用的 ACPI、Kext、Kernel Patch、DeviceProperties、USB 映射和启动参数。
3. 公开前清除或替换 `SystemSerialNumber`、`MLB`、`SystemUUID`、`ROM` 等身份字段，并检查其他文件中是否存在密码、令牌、私钥、个人路径或网络标识。
4. 不要把 FileVault 恢复密钥、个人日志、系统分区数据、Preboot 数据或无关备份放进仓库。
5. 使用者必须根据自己的硬件生成 SMBIOS，并自行验证配置；脱敏配置不应直接覆盖作者自己的 EFI。

## 本项目的适用范围与使用提醒

- 本项目是针对一台 FA507UV 的实际记录，不等同于整个 FA507UV 产品系列的兼容性报告。
- 机器实际硬件 ID、BIOS 版本、USB 端口布局和驱动版本可能与其他用户不同。
- 文档中会区分作者实测、作者反馈、推测和未测试内容；请结合对应章节判断可信程度。
- 修改 EFI 前先备份当前可启动版本，并确保有可用的恢复方式。
- 不建议只复制某一条启动参数或 Kext 就判断问题能够解决；驱动、加载顺序、ACPI、设备属性和系统版本可能共同影响结果。
